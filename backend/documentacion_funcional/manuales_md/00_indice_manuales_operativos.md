# Indice De Manuales Operativos

## Objetivo

Esta carpeta contiene manuales en formato Markdown para usuarios operativos. Cada archivo explica una ruta del sistema con lenguaje funcional: que ve el usuario, para que sirve cada componente, que boton debe usar y cual es el resultado esperado.

Estos manuales son la base para crear luego manuales HTML visuales con capturas.

## Como Usarlos

- Leer primero el manual de la ruta que opera el usuario.
- Pegar capturas donde dice `Imagen sugerida`.
- Mantener las capturas cortas y enfocadas en el componente descrito.
- No incluir el boton `Configuracion` en el manual de usuario.

## Componentes Recurrentes

- Empresa activa: caja o empresa sobre la que se trabaja.
- Cuenta activa: cuenta/caja exacta cuando una empresa tiene mas de una.
- KPIs: resumen de saldos, ingresos, salidas, gastos y ganancias.
- Carga Excel: panel para importar operaciones del banco.
- Tabs operativos: bandejas de trabajo como Efectivizacion, Pago Deuda, Derivados, POS, Movimientos y Retenidos.
- Acciones rapidas: botones que aplican cambios a una o varias filas seleccionadas.
- Cierre: congela el ciclo de caja de la empresa/cuenta activa.
- Descargar: genera reporte del dia o del cierre historico.
