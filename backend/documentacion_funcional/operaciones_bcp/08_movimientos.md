# Movimientos

## Objetivo

Consultar el impacto financiero generado por las operaciones de la empresa seleccionada.

## 1. Abrir Tab Movimientos

Seleccionar el tab `Movimientos`.

**Imagen 1:** pegar captura del tab `Movimientos`.

## 2. Usar Filtros

Filtros disponibles:

- Todos
- Efectivizacion
- Pago Deuda
- Otros

**Imagen 2:** pegar captura de los filtros de movimientos.

## 3. Buscar Por DNI

Usar el campo DNI para ubicar movimientos de un cliente.

**Imagen 3:** pegar captura del campo DNI con una busqueda.

## 4. Revisar Ingresos Y Salidas

Columnas principales:

- Origen
- Movimiento
- DNI
- Codigo
- Empresa
- Ingreso
- Salida
- Fecha

**Imagen 4:** pegar captura de la tabla de movimientos.

## Resultado Esperado

El usuario puede comprobar ingresos, salidas y origen de cada movimiento.
