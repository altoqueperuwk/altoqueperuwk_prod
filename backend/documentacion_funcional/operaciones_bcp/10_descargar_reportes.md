# Descargar Reportes

## Objetivo

Generar reportes PDF o Excel de la empresa y periodo seleccionado.

## 1. Seleccionar Periodo

Usar `Hoy` o seleccionar una fecha historica de cierre.

**Imagen 1:** pegar captura del selector de fecha.

## 2. Descargar

Presionar `Descargar`.

El sistema genera los archivos disponibles para el periodo seleccionado.

**Imagen 2:** pegar captura del boton `Descargar`.

## 3. Revisar PDF

El PDF muestra resumen de KPIs y detalle operativo.

Revisar:

- Datos de empresa y banco
- KPIs principales
- Efectivizaciones pagadas
- Pago Deuda
- Movimientos

**Imagen 3:** pegar captura de vista previa o PDF generado.

## 4. Revisar Excel

Validar las hojas generadas con el detalle operativo.

**Imagen 4:** pegar captura del archivo Excel descargado.

## Resultado Esperado

El usuario obtiene el reporte correcto para revision, archivo o entrega.
