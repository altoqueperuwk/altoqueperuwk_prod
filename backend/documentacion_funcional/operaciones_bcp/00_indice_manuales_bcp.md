# Manuales Rapidos BCP

## Objetivo

Guias cortas para que el usuario aprenda las operaciones principales de `/operaciones/bcp`.

Cada archivo esta pensado para tener pocas capturas y explicar una sola accion del sistema.

2. `02_modales_operativos.md`
3. `03_cargar_y_procesar_archivo.md`
4. `04_acciones_rapidas_efectivizacion.md`
5. `05_atender_efectivizacion.md`
6. `06_pago_deuda_en_bcp.md`
7. `07_derivados_y_pos.md`

9. `09_cierre_de_caja.md`
10. `10_descargar_reportes.md`

## Consideraciones

- No se documenta el boton `Configuracion`.
- Las capturas deben pegarse debajo de cada bloque `Imagen`.
- Mantener textos cortos para que el usuario pueda consultar rapido mientras opera.
