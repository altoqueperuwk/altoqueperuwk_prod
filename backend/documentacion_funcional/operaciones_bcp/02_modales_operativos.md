# Modales Operativos

## Objetivo

Registrar operaciones manuales sin cargar archivo bancario.

## 1. Mover Saldo

Usar este modal cuando se necesita mover dinero desde la caja actual hacia otra empresa/cuenta.

Completar:

- Cuenta origen
- Empresa destino
- Cuenta destino
- Monto a depositar

Luego presionar `Guardar`.

**Imagen 1:** pegar captura del modal `Mover Saldo`.

## 2. Ingreso Y Salidas

Usar este modal para registrar movimientos manuales de caja.

Seleccionar el tipo de movimiento:

- Ingreso
- Salida

Completar monto y concepto, luego presionar `Guardar`.

**Imagen 2:** pegar captura del modal `Ingreso y Salidas`.

## 3. Operacion Efectivizacion

Usar este modal para registrar una efectivizacion manual.

Completar:

- Codigo Operacion
- DNI
- Monto
- Comunidad

Luego presionar `Guardar`.

**Imagen 3:** pegar captura del modal `Operacion Efectivizacion`.

## Resultado Esperado

El sistema registra la operacion o movimiento y actualiza los KPIs de la empresa.
