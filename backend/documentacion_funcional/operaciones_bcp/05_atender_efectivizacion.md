# Atender Efectivizacion

## Objetivo

Revisar las operaciones de efectivizacion y atenderlas segun su estado.

## 1. Abrir Tab Efectivizacion

Seleccionar el tab `Efectivizacion`.

Aqui se visualizan las operaciones cargadas por archivo o registradas manualmente.

**Imagen 1:** pegar captura del tab `Efectivizacion`.

## 2. Usar Filtros

Filtros disponibles:

- Todos
- Pendientes
- Rechazados
- Pagados

**Imagen 2:** pegar captura de filtros rapidos.

## 3. Buscar Operaciones

Buscar por:

- Cod. Operacion
- DNI

**Imagen 3:** pegar captura de busqueda por codigo o DNI.

## 4. Revisar Columnas

Validar datos principales: facturacion, codigo, DNI, comunidad, cuentas, monto, comision, transferencia, estado y hora.

**Imagen 4:** pegar captura de la tabla con una fila visible.

## 5. Boton PD

El boton `PD` permite enlazar la operacion con una devolucion de Pago Deuda cuando exista coincidencia.

**Imagen 5:** pegar captura del boton `PD` en la fila.

## 6. Acciones Por Fila

Desde el menu de acciones se puede usar:

- Com. Especial
- Com. Extra
- Directo
- Visualizar

**Imagen 6:** pegar captura del menu de acciones por fila.

## Resultado Esperado

El usuario identifica, filtra y atiende correctamente las operaciones de efectivizacion.
